## Эмоуты 7TV

- Кнопка **7TV** появляется у формы обычного чата и у формы личных сообщений.
- Список берётся из каталога эмоутов, который уже загружает сам сайт для текущего канала; при смене канала используется его каталог.
- Расширение не запрашивает наборы 7TV/IVR и не подменяет смайлы в чате. Для попапа оно получает ID из каталога сайта, кэширует картинки в IndexedDB расширения и при ошибке CDN использует endpoint сайта.
- В окне эмоутов доступны поиск, вкладки **Все**, **Избранное** и **Недавние**. Нажатие на эмоут вставляет его название в активное поле ввода.
- Размер эмоутов в сообщениях можно выбрать в настройках: S, M, L или XL.
- Анимацию эмоутов в попапе можно отключить в настройках; в сообщениях чата она не меняется.
- При наведении на смайл в сообщении или списке появляется карточка с превью и названием.
- Список недавних формируется по эмоутам, отправленным через обычный чат; его размер настраивается.
- Кэш картинок можно очистить в настройках.

Сообщения используют штатные смайлы сайта. В настройках расширения их можно скрыть в чате; попап и автодополнение используют каталог текущего канала.

## Чат общее, журнал, сообщения и тд

- В настройках можно менять порядок вкладок и скрывать ненужные.
- В обычной форме чата доступны история до 50 отправленных сообщений (стрелки вверх/вниз), автодополнение ника по `Tab` после `@` и вставка эмоутов.
- Кнопка перед значками игрока открывает его историю сообщений из вкладок **Общее**, **Ремёсла**, **Гильдия** и **Торговля**. Окна можно перемещать, сворачивать и открывать несколько раз; в памяти текущей страницы хранится до 500 сообщений на вкладку для каждого игрока. Кнопку можно скрыть в настройках **Чат → Кнопки в чате**.
- Markdown-разметку можно выключить во вкладке **Чат → Сообщения**; по умолчанию она включена. Обратный слеш экранирует маркер: `\*текст*` отображается как `*текст*`.
- Во вкладке **CSS** можно скопировать промпт для генерации темы, выбрать CSS в браузере тем из каталога GitHub, загрузить CSS локальным файлом, а также применить, скачать или сбросить стиль. Каталог загружается с GitHub Raw, а при недоступности используется jsDelivr. Сброс кеша CDN не выполняется. Каталог ограничен 100 КиБ и проверяется. CSS выбранной темы также проверяется до помещения в редактор. После загрузки просмотрите CSS и нажмите **Применить CSS**. Чтобы получить более точную тему, отправьте промпт нейросети, следующим сообщением опишите стиль и приложите скрин исходного чата и изображения-референсы. Селекторы CSS должны начинаться с `.cy-chat` (например, `.cy-chat .cy-chat-l li`); доступны `@media` и `@keyframes`. Изображения задаются прямыми публичными HTTPS-ссылками в `url()`; при загрузке картинки браузер обращается к указанному хосту. Локальный импорт изображений и упаковка картинок в тему не поддерживаются.
- CSS можно загружать и скачивать как обычный `.css`-файл. Локальный импорт изображений и упаковка картинок в тему не поддерживаются.
- Личные сообщения остаются отдельной сущностью сайта. Скрипт обрабатывает их отображение и добавляет кнопку 7TV в форму лички, но оставляет отправку личных сообщений логике сайта.
- Кнопка **imgBB** у поля ввода открывает выбор изображения с предпросмотром, списком последних 10 ссылок и избранным. Изображение можно добавить в избранное прямо из предпросмотра, вставить ссылку в сообщение или сразу отправить её. Показ кнопки настраивается во вкладке **Чат → Кнопки в чате**. Ссылки остаются обычными `https://ibb.co/...` и при включённой обработке продолжают преобразовываться существующим способом.
- Ссылки HTTPS в сообщениях становятся кликабельными. Дополнительно можно включить преобразование HTTPS-ссылок при отправке; эта настройка выключена по умолчанию.
- В настройках можно отдельно включить показ изображений Imgbb по ссылкам. Для обычных ссылок Imgbb будет показан предпросмотр, исходная ссылка останется кликабельной. Архитектура поддерживает добавление адаптеров других хостингов.

## Пинги и фильтры

В настройках **Пинги и фильтры** можно:

- задать ники и варианты имени, по которым распознаются упоминания;
- включить или выключить автодополнение ника по `Tab`;
- настроить звуковой сигнал и громкость, а также загрузить собственный аудиофайл размером до 2 МБ;
- включить отдельные звуковые уведомления для новых личных сообщений, выбрать пресет или загрузить собственный звук;
- фильтровать звуковые уведомления ЛС по никам в режиме чёрного или белого списка;
- скрывать сообщения выбранных отправителей или сообщения с заданными словами и фразами;
- включить режим показа только сообщений с упоминаниями.

Для ника в чате также доступно контекстное действие добавления в чёрный список.

## Отказ от ответственности

Неофициальный проект, не связанный с авторами Legiongame gg или 7TV. Изменения сайта, особенно разметки и API чата, могут потребовать обновления скрипта.
