  7TV для чата Multidonate Play
</div>  
Скрипт для Tampermonkey: добавляет в чат игры эмоуты 7TV. Названия эмоутов в сообщениях заменяются картинками, а справа от кнопки отправки появляется кнопка 7TV.


**Установка**
Установи расширение Tampermonkey (Chrome, Edge, Firefox, Opera).
В Chrome и Edge: chrome://extensions → Tampermonkey → «Подробнее» → включи «Разрешить пользовательские скрипты» (в некоторых версиях нужен «Режим разработчика»).
Создай новый скрипт в Tampermonkey и вставь код целиком (или открой ссылку на .user.js, если скрипт выложен).
Открой игру: https://play.multidonate.ru/c/<канал>/.
При первом запуске Tampermonkey спросит доступ к 7tv.io, cdn.7tv.app и api.ivr.fi. Нажми «Всегда разрешать домен».


**Как пользоваться**

Нажми 7TV рядом с кнопкой ➤. В окошке можно:

Указать ник стримера на Twitch (например, zakvielchannel) или вставить ссылку на его канал. По умолчанию берётся канал из адреса страницы.
Выбрать размер эмоутов: S, M, L, XL.
Посмотреть все эмоуты канала и глобальные, с поиском. Клик по эмоуту вставляет его название в поле чата.

Закрыть окошко: Esc, × или клик вне него.

**Важно**
Эмоуты видишь только ты. Остальные игроки без скрипта увидят в чате обычный текст с названием эмоута.
Скрипт обращается только к 7tv.io, cdn.7tv.app и api.ivr.fi и работает только на play.multidonate.ru.
Картинки кешируются в браузере, поэтому после первого визита эмоуты появляются быстро.
Если что-то не работает
Нет кнопки 7TV: открой чат и обнови страницу.
Нет картинок: проверь разрешения доменов в Tampermonkey (настройки скрипта → «XHR Security») и посмотри ошибки в консоли (F12).
Сбросить кеш картинок: F12 → Application → IndexedDB → t7img → Delete database.
Кнопка задвоилась: у тебя установлено две копии скрипта, удали лишнюю.


**Отказ от ответственности**

Это неофициальный скрипт, не связанный с автором игры и командой 7TV. Если разметка чата на сайте изменится, скрипт может перестать работать до обновления.
